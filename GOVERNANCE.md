# How the deck gallery is run

The gallery follows LernLab's [GOVERNANCE.md](https://github.com/n1m5l5ss/lernlab/blob/dev/GOVERNANCE.md): the roles, how to join, how decisions are made and how someone takes over are the same for both repositories. The team is in [MAINTAINERS.md](MAINTAINERS.md).

For decks in particular:

- **A deck goes live only after one approval** from a reviewer or maintainer, and only with the automatic check green. Nothing is published automatically.
- **Every pull request gets a summary** (deck name, cards, language, licence, check result and the first cards), so a reviewer can decide straight from the email notification.
- **No answer for 7 days:** a bot labels the pull request `waiting-for-review` and mentions the team.
- **Reviewers check** that the cards are sensible and correct enough to learn from, that the licence fits (the sender made the cards or may share them), and that nothing breaks the Code of Conduct.
- **To join** as a reviewer of decks, use the [Join the team form](https://github.com/n1m5l5ss/lernlab/issues/new?template=join_team.yml) and pick "The deck gallery".
